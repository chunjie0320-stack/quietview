# 美团营销活动 - 标签规范

营销组件标签类型可分为：**信息区标签**、**内容叠加标签**、**异形特殊标签**。

> ⚠️ **同一卡片上建议仅展示1个深色标签**

---

## 标签分区（商卡）

### A区：业务/时效信息
位置：图片区叠加标签
- 遵循《美团基础设计规范》业务用色
- 使用宽松标签
- 右上圆角0.12rem

### B区：品/店/状态信息
位置：标题前叠加标签
- 遵循《美团基础设计规范》
- 推荐浅色底标签
- 可最多2个并列
- 如用深色标签，规避和图片区深色标签同时出现

**常见类型**：
- 店铺名称、品牌名称：如"奈雪的茶(望京店)"、"麦当劳"
- 状态/活动logo：如"神券仓"、"小直播"、"打料"

### C区：价格决策信息
位置：价格辅助标签
- 遵循《美团基础设计规范》
- 默认彩色描边标签
- 文字用色：#FF2D19

**常见类型**：
- 折扣/满减：如"07折"、"满30减18"
- 倒计时/活动价：如"会员价"、"秒杀"

## 标签样式类型

### 拼接标签（价格决策标签）

| 属性 | 规范 |
|------|------|
| 适用场景 | 一个标签内包含两种类型信息 |
| 尺寸 | 推荐选择"标准"，屏效要求高可使用"紧凑" |
| 示例 | `字 \| 标签信息` |

### 常规描边标签

| 属性 | 规范 |
|------|------|
| 适用场景 | 一个标签内仅有一种类型信息 |
| 尺寸 | 标准/紧凑 |
| 样式 | 描边标签 |

### 深色标签

| 属性 | 规范 |
|------|------|
| 适用场景 | 品牌/活动强调 |
| 默认用色 | 颜色使用遵循《美团基础设计规范》 |
| 尺寸 | 推荐"标准"，屏效要求高可使用"紧凑" |

### 浅色标签

| 属性 | 规范 |
|------|------|
| 适用场景 | 用于文案区叠加标签 |
| 尺寸 | 标准/紧凑 |

### 旗帜形态标签（异形特殊标签）

| 属性 | 规范 |
|------|------|
| 适用场景 | **仅用于榜单组件** |
| 用色 | 气泡颜色遵循《美团基础设计规范》，榜单标签用色默认统一 |
| 示例 | TOP1、TOP2、TOP3 |

## 商家信息规范

| 属性 | 规范 |
|------|------|
| 图标 | 使用《美团基础设计规范》中的图标样式 |
| 信息分割 | 商家基础服务信息间距：0.12rem |

---

## 反馈状态规范（已售罄等）

| 属性 | 规范 |
|------|------|
| 使用场景 | 用于商卡中反馈信息 |
| 提示语 | 文字色：#FFFFFF，背景遮蔽色/普通 |
| 文字 | 字段固定3字（如"已抢光"） |
| 使用规范 | 置于商品图居中位，商卡按钮置灰态，文字内容以及商品图50%透明度 |
