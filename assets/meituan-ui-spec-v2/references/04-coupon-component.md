# 美团营销活动 - 领券组件规范

用于展示可领取的优惠券信息。

---

## 组件类型

### 按列数分类

| 类型 | 说明 |
|------|------|
| 单列券 | 一行显示1个券 |
| 双列券 | 一行显示2个券 |
| 三列券 | 一行显示3个券 |
| 三列以上 | 一行显示3个以上券 |

### 按样式分类

| 样式 | 适用背景 |
|------|---------|
| 白底样式 | 适用于有色相背景的情况 |
| 粉底样式 | 适用于白色背景的情况 |
| 红包样式 | 适用于强氛围的情况 |
| 白卡（三列以上） | 适用于白色背景的情况 |

---

## 券信息字段规范

### 无商品图样式

| 字段 | 规范 |
|------|------|
| 标签（可选） | 文案不超过4个字；默认字体选择苹方；可根据需求展示IP（有商品情况下建议谨慎使用标签） |
| 主标题（可选） | 单列：不超过10个字；双列：不超过9个字；三列：不超过7个字；三列以上：不超过6个字 |
| 金额 | 金额不超过2位数时使用0.6rem字号；金额超过2位数时使用0.54rem字号；文案不建议超过4位数 |
| 门槛信息 | 文案不建议超过5位数 |
| 按钮 | 文案不超过4个字；按钮颜色默认使用辅助色/R3 |
| 尺寸 | 可自行调整适配，遵循美团基础设计规范 |

### 有商品图样式

| 字段 | 规范 |
|------|------|
| 标签（可选） | 文案不超过4个字，可展示IP |
| 主标题 | 单列：不超过10个字；双列：不超过9个字；三列/以上：不超过7个字 |
| 金额 | 不超过2位数时0.6rem；超过2位数时可缩小字号（遵循美团规范）；不建议超过4位数 |
| 门槛信息 | 文案不建议超过5位数 |
| 按钮 | 文案不超过4个字；颜色遵循最新规范 |
| 颜色 | 可选深/浅色系，色值遵循美团最新规范 |
| 尺寸 | 可自行调整适配，遵循美团最新规范 |

---

## 状态规范

### 进行中状态
- 按钮：正常颜色，文案不超过4个字
- 红包样式的按钮整体50%透明

### 未进行中状态
- 按钮：呈灰色线性，文案不超过4个字

---

## 商家+品类券

适用于商家与品类联合券场景，支持金额和门槛信息展示，结构同上。

---

## 案例说明

- 券名称限六字 / 七字 / 十字：根据列数决定长度限制
- 满XX可用：门槛信息
- 已抢XX%：进度条状态展示
- 可展示到期时间，如：8月18日到期
