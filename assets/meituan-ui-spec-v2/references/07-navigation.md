## 底部规则文案

| 属性 | 规范 |
|------|------|
| 标题 | 字号0.32rem，字重中粗体；与内容间距0.24rem |
| 正文 | 字号0.24rem，字重常规体；行间距0.16rem |
| 容器 | 宽度7.02rem；高度随文字内容自适应；页面内上下边距0.24rem、左右边距0.24rem |

## 一级Tab

### 文字型Tab

| 属性 | 规范 |
|------|------|
| 间距（≤4个选项） | 自适应等分 |
| 间距（>4个选项） | 页面左边距0.24rem，选项间距0.48rem |
| 文字 | 字号0.32rem；选中态字重中粗；未选中态字重常规 |
| 颜色 | 业务可自行调整，遵循《美团基础设计规范》 |
| 指示器 | 宽0.64rem，高0.08rem |
| 非通栏tab | Tab在卡片内部时同上规则 |

### icon+文字型Tab

| 属性 | 规范 |
|------|------|
| 间距（≤3个选项） | 自适应等分 |
| 间距（>3个选项） | 页面左边距0.24rem，选项间距0.48rem |
| 文字 | 字号0.32rem；选中态字重中粗；未选中态字重常规 |
| 图片 | 建议尺寸0.33rem × 0.33rem |
| 颜色 | 业务可自行调整 |
