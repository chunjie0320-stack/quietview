# 美团营销活动 - 按钮规范

按钮按造型可分为**常规按钮**、**促销按钮**。按钮用色和状态遵循《美团基础设计规范》。

---

## 常规按钮

用于基础操作，单色突出功能性与可识别性。

### 常规按钮-强化

| 属性 | 规范 |
|------|------|
| 默认用色 | 按钮区底色为主色，颜色使用遵循《美团基础设计规范》 |
| 使用场景 | 首屏头部组件、福利资产组件、玩法组件 |
| 高度 | 默认0.8rem（无包框时使用，组件无包框不建议使用"一键领取"大按钮） |

### 常规按钮-弱化

| 属性 | 规范 |
|------|------|
| 默认用色 | 按钮区底色为辅助用色 #FFF1F0 |
| 价格字体用色 | 统一 #FF2D19 |
| 使用场景 | 日常促销及多按钮场景，例如：商品供给组件、双列feed组件、商家组件、品牌瓷片墙等 |

---

## 促销按钮

促销型强化按钮仅在**限时抢购、重点活动等特定场景**下使用，通过颜色突出活动的紧迫感和吸引力。合理区分弱化与强化促销按钮的使用场景，保持页面信息层级清晰。

### 促销按钮-弱化

| 属性 | 规范 |
|------|------|
| 样式 | `¥72.88¥80 抢` 渐变/填充样式 |
| 默认用色 | 按钮区底色为辅助用色 #FFF1F0，价格字体用色统一 #FF2D19 |
| 使用场景 | 日常促销及多按钮场景：商品供给组件、双列feed组件、商家组件、品牌墙等；按钮高度和规范案例保持一致 |

### 促销按钮-强化

| 属性 | 规范 |
|------|------|
| 样式 | `抢购` 渐变强色样式 |
| 默认用色 | 按钮区底色为辅助用色 #FFF1F0，价格字体用色统一 #FF2D19 |
| 使用场景 | 单一促销转化场景：仅承载秒杀/抢购等高优先级营销内容，无其他多按钮场景拼接，最大化用户关注转化 |

---

- 资片入口按钮默认弱化处理

| 场景 | 按钮底色 | 价格/文字颜色 |
|------|---------|-------------|
| 常规弱化 | #FFF1F0 | #FF2D19 |
| 促销弱化 | #FFF1F0 | #FF2D19 |
| 促销强化 | 辅助色（渐变） | #FF2D19 |
