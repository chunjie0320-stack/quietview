# 美团营销活动会场UI规范 - 整体概览

## 适用场景

本规范适用于**营销场域**，包括：
- 综合大促活动（618、双11等）
- 日常活动
- 品牌活动

## 设计原则

通过差异化排版与标准化组件体系，实现：
- 高效复用
- 灵活扩展
- 体验一致
- 提升用户转化率和平台运营效率

## 会场整体结构（从上到下）

```
顶部导航（头图 + 导航栏）
  ↓
首屏区域（首屏目标效果 + 权益获取组件）
  ↓
权益区（楼层标题 + 券/资产组件，建议1-2个组件）
  ↓
流量分发区（楼层标题 + 频道入口等）
  ↓
推荐区（商品/商家供给组件，建议1个组件）
  ↓
底部规则 + 底部导航
```

## 组件拼用建议

- **首屏**：素材 + 权益获取（按钮可强化）
- **权益获取区**：建议1-2个组件，不同类型的组件不建议拼接多个使用，按钮可强化
- **推荐商品区**：建议1个组件，按钮弱化
- **不同类型的组件**：不建议拼接多个使用

## 基础规范引用

页面配色、图标样式遵循《美团基础设计规范》（基础规范C2/LP/CO）。
