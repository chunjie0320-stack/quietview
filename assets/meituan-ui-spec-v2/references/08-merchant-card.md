# 美团营销活动 - 商卡（商品/商家卡片）组件规范

用于展示商卡核心信息（如图片、名称、价格、促销标签等）。

以短文本和基础标签的形式快速传达关键决策信息（如品类、状态、优惠等），拆分三大类。

---

## 商卡结构

### 标签分区（参见 06-tags.md）
- A区：图片区叠加标签（业务/时效信息）
- B区：标题前叠加标签（品/店/状态信息）
- C区：价格辅助标签（折扣/满减/倒计时/活动价）

---

## 辅助信息规范

辅助信息主要包含：商品属性、店铺信息、服务信息、评价信息 4大类。

| 类型 | 示例 |
|------|------|
| 评分评价 | "5.0分"、"好评率80%"、"望京奶茶人气榜第1名"、"点评高分" |
| 商品属性 | "6月30日"、"退"、"冷藏"、"新品上市"、"海景房" |
| 店铺信息 | "望京/酒仙桥"、"¥154/人"、"销量9999+"、"月售9999"、"9475条评价" |
| 服务信息 | "免配送费"、"美团快递"、"起送¥20"、"配送¥3"、"多店通用"、"行李寄存"、"假一赔四"、"超好吃推荐" |

**颜色**：不带底色，颜色使用遵循《美团基础设计规范》，业务自定义

**间距**：0.12rem

**使用规范**：三列及以上商卡情况下，辅助信息和标签二选一

## 商卡布局类型

### 单列卡

| 属性 | 规范 |
|------|------|
| 图片比例 | 建议1:1或4:3 |
| 圆角 | 0.24rem（大卡片） |
| 标题 | 0.32rem中黑，#111111 |
| 辅助信息 | 0.22rem-0.24rem |
| 价格 | 按价格规范 |
| 按钮 | 弱化/强化按钮 |


### 双列卡精确数值规范（2025最新）

> 以下为双列商卡内容区的精确像素/rem约束，优先级高于上方通用描述。

#### 1. 容器与整体布局

| 属性 | 数值 | rem |
|------|------|-----|
| 内边距 (Padding) | 16px | 0.16rem |
| 底部圆角 | 0 0 16px 16px | 0rem 0rem 0.16rem 0.16rem |
| 背景色 | #FFFFFF | — |

> 注：图片区无内边距，圆角仅底部，顶部随图片直角。

#### 2. 标题区

| 元素 | 字号 | 字重 | 颜色 |
|------|------|------|------|
| 品牌前缀 | 0.28rem | 500 | #7A3100 |
| 商品名称 | 0.28rem | 500 | #111111 |

- 品牌前缀宽度 Auto，与商品名称同行展示
- 商品名称第一行宽度 Auto，第二行固定宽度 3.11rem，超出截断（`overflow: hidden; text-overflow: ellipsis`）

#### 3. 辅助信息区

| 元素 | 字号 | 行高 | 字重 | 颜色 |
|------|------|------|------|------|
| 距标题区 Margin-Top | — | — | — | 0.12rem |
| 评分数字 | 0.22rem | 0.32rem | 600 | #FF7700 |
| 商圈/好评率 | 0.22rem | 0.32rem | 400 | #555555 |

**营销标签（折数等）**：
- 高度：0.32rem
- 左右内边距：0.08rem
- 描边：1px solid #FFC6C1
- 圆角：0.06rem
- 内部 Flex 垂直居中
- 文字颜色：#FF2D19

#### 4. 价格与操作区

**整行容器**：高度 0.52rem，`display: flex; justify-content: space-between; align-items: center`

**现价（强焦点）**：

| 元素 | 字号 | 字重 | 颜色 | 字体 |
|------|------|------|------|------|
| ¥ 符号 | 0.26rem | 700 | #FF2D19 | MTNewDigital |
| 整数部分 | 0.4rem | 700 | #FF2D19 | MTNewDigital |
| 小数部分 | 0.26rem | 700 | #FF2D19 | MTNewDigital |

> ¥符号、整数、小数必须统一使用 MTNewDigital，禁止混用苹方。

**划线原价（弱焦点）**：
- 字体：PingFang SC
- 字号：0.22rem，字重 400
- 颜色：#999999
- `text-decoration: line-through`

**行动按钮（"抢"）**：

| 属性 | 数值 | rem |
|------|------|-----|
| 高度 | 48px | 0.48rem |
| 左右 Padding | 20px | 0.2rem |
| 圆角 | 24px（胶囊） | 0.24rem |
| 背景色 | #FFF1F0 | — |
| 文字字号 | 0.32rem | — |
| 文字字重 | 600 | — |
| 文字颜色 | #FF2D19 | — |

## 横卡示例

适用于一行单列卡布局：

```
[商品图] 商品名称标题（1行）
         辅助信息（如起送价、配送费）
         标签组（折扣、活动）
         ¥72.88 券后价¥86          [按钮]
```

## 商家+品组件

适用于店铺带商品展示：

```
[店铺logo] 店铺名称（奈雪的茶、望京店）
           评分/销量/配送信息
           [商品1] [商品2] [商品3]
           ¥28.9券后   ¥28.9券后   ¥28.9券后
```

## 榜单组件（特殊）

| 属性 | 规范 |
|------|------|
