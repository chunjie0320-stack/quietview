# 完整流水线设计（8步）

> 来源：2026-04-10 产品设计讨论（projects/foodsearch.md）
> 当前 Skill 实现：步骤①②④，其余步骤待开发或对接外部产品

```
① 语义输入层（运营输入 → 结构化参数）        ← 本 Skill Phase 1
② 自动分析热点                               ← 本 Skill Phase 1+2
③ 自动寻找痛点                               ← 待开发
④ 自动化生产选题                             ← 本 Skill Phase 2+3
⑤ 用户确认选题（人工介入点）                  ← 人工
⑥ 自动生产内容（微信/小红书风格，配图用fal-ai）← 待开发
⑦ 基于内容选定会场样式                        ← 待开发
⑧ 自动构建会场（对接现有独立产品）             ← 对接外部
```

## 步骤③ 痛点挖掘（待开发）

核心逻辑：从抓取内容中识别用户抱怨/未被满足的需求

- 商业化：找"找不到好的XXX""XX太贵了""XX没有XXX"等供给缺口
- 内容型：找"好累""太难了""没人理解"等情绪出口

## 步骤⑥ 内容生产（待开发）

- 微信风格：长图文，有标题+副标题+正文+结语
- 小红书风格：短平快，封面图文字+正文5-7条+话题标签
- 配图：调用 fal-ai skill，由 Claude 写生图 prompt

## 步骤⑦ 会场样式匹配（待开发）

基于内容类型自动推荐：
- 内容型 → 瀑布流/时间轴样式
- 商业化 → 品类卡片/促销横幅样式
